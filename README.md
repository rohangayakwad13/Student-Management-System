# 🎓 Student Management System

A **Python-based Student Management System** built around a real-world problem: managing student records efficiently and accurately.

This project is part of a **Problem Solving Series**, where a real-world problem is first understood and broken down into requirements, logic, and smaller tasks before writing the actual Python solution.

The system allows users to **add, search, correct, and delete student records** through an interactive terminal-based menu.

---

## 📌 Project Description

Managing student records manually can become difficult when the number of students increases.

This project provides a simple command-line solution where student information can be stored and managed digitally.

The project focuses not only on writing Python code, but also on understanding **how to convert a real-world problem into a working software solution.**

### Problem → Requirements → Logic → Code → Testing → Solution

---

## 🚀 Features

* ➕ Add Student
* 🔍 Search Student
* ✏️ Correct/Update Student
* 🗑️ Delete Student
* 💾 Store data using JSON
* 📂 Load and save student records
* 🖥️ Interactive terminal menu
* ✅ Input validation
* 🔄 Complete CRUD-style record management
